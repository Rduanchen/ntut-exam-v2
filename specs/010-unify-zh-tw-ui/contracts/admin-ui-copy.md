# 管理端介面文字契約

## 適用範圍

管理端九個導覽區域：`/manage`、`/config`、`/judge`、`/score`、`/student`、`/anticheat`、`/log`、`/connection`、`/device`；另含共用元件、對話框與瀏覽器頁面名稱。本契約描述使用者看到的文字，不改變路由或資料交換格式。

## 導覽與共用用語

| 路由或概念 | 顯示文字 |
| --- | --- |
| `/manage` | 考試管理 |
| `/config` | 考試設定 |
| `/judge` | 評測 |
| `/score` | 成績 |
| `/student` | 學生 |
| `/anticheat` | 防作弊 |
| `/log` | 紀錄 |
| `/connection` | 連線管理 |
| `/device` | 設備監控 |
| `Save / Cancel / Refresh / Delete` 等一般動作 | 儲存／取消／重新整理／刪除 |
| `Loading / No data / Failed` 等情境 | 載入中／暫無資料／操作失敗，並依情境補足對象 |

同一概念跨頁須沿用同一譯名。若某頁因業務語義需要不同譯名，須在文案清冊寫明差異。

| 共用概念 | 顯示文字 |
| --- | --- |
| 設備已綁定且在線 | 線上 |
| 設備離線 | 離線 |
| 設備未綁定 | 未綁定 |
| 等待登入 | 等待登入 |
| 評測部署測試 | 部署測試 |
| 系統故障 | 系統錯誤；不得寫成學生答題錯誤 |
| 學生提交造成的失敗 | 學生作答錯誤 |
| 設定來源 `config` | 設定檔指定 |
| 設定來源 `env` | 環境變數 |
| 設定來源 `default` | 預設值 |
| 設定來源 `clamped` | 設定值遭拒絕（未採用） |

## 顯示與資料值邊界

1. 翻譯導覽、標題、欄位、按鈕、分頁、篩選選項、表格標頭、提示、警告、空白與載入狀態，以及介面自身產生的錯誤訊息。
2. 保留路由、事件、API 欄位、列舉值、學生或管理員輸入、考卷內容、程式碼、日誌原文、檔名及識別碼。
3. IP、UUID、JSON、CSV、Piston、程式語言名稱、ms、MB 等可保留英文；在可能誤解的首次使用處以中文交代意思。
4. AC、WA、TLE、MLE、CE、SE 等結果代碼保留，旁邊提供正確中文含義。歸因值 `submission` 與 `system` 的顯示需清楚區分學生作答問題與系統故障。
5. 未知狀態或外部診斷不得臆測翻譯；顯示中文情境與原始值。診斷內容中的路徑、原碼與系統訊息保持原文。
6. 設定來源的 `clamped` 必須表達「設定值超出允許範圍而未採用」，不能表達成「已採用調整後數值」。

## 高風險互動

- 線上設備解除綁定及註銷警告，須完整說明學生會立即登出及可能影響考試進度。
- 畫面以繁體中文要求輸入 `CONFIRM`；驗證仍精確比對 `CONFIRM`，未輸入或輸入其他字串不能確認。
- 資料重設與演練清除提示須清楚說明清除後果，取消操作不能觸發清除。

## 可用性與驗收

- 頁面主要內容語言及瀏覽器頁面名稱為繁體中文。
- 中文警告在窄螢幕與表格內仍能看到完整關鍵後果、確認條件及操作選擇。
- 每個導覽區域須走查正常、載入、空白、錯誤及適用的高風險狀態；對照 [quickstart.md](../quickstart.md)。
