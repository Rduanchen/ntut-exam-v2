# Quickstart: 管理端繁體中文驗證

## 前置條件

- 在專用 `feat/010-unify-zh-tw-ui` 分支或隔離工作樹執行；目前 `feat/009-download-sqlite-backup` 有其他未提交工作。
- 安裝專案依賴；以本機或測試環境提供管理端所需資料。高風險操作只在可重設的測試資料上走查。
- 對照 [介面文字契約](contracts/admin-ui-copy.md) 與 [資料模型](data-model.md)。

## 自動驗證

在倉庫根目錄執行：

```sh
pnpm --filter frontend typecheck
pnpm --filter frontend test
pnpm --filter frontend build
```

預期：型別檢查、元件與狀態測試、正式建置均通過。更新所有因英文文案調整而失效的既有斷言；外部原始錯誤文字與資料值相關斷言仍保留。前端現有覆蓋率設定只計入部分檔案，不能以其通過視為全前端 100% 覆蓋率。

## 逐頁走查

啟動管理端後，依序開啟九個導覽區域：考試管理、考試設定、評測、成績、學生、防作弊、紀錄、連線管理、設備監控。

每頁檢查：

1. 導覽、頁面標題、分頁、欄位、按鈕、篩選、表格及說明為一致的台灣繁體中文；保留英文皆符合契約。
2. 載入、空白、成功、失敗狀態可理解；若後端回傳英文診斷，畫面有中文情境且原文仍可讀。
3. 資料值、識別碼、考卷與使用者內容未被翻譯或改動。
4. 窄螢幕寬度下，警告後果、確認條件與主要按鈕可完整閱讀。
5. 瀏覽器頁面名稱與內容語言為繁體中文。

## 關鍵情境

| 情境 | 操作 | 預期 |
| --- | --- | --- |
| 設備解除綁定 | 對線上測試設備開啟對話框，嘗試空白、錯字及 `CONFIRM`，再測取消 | 中文警告完整；只有正確字串能確認；取消不執行 |
| 設定來源 | 查看預設、環境、設定檔與 `clamped` 標記 | 顯示來源與「未採用」語義正確 |
| 評測失敗 | 查看學生程式錯誤與系統故障樣本 | 原始代碼保留；中文歸因不同，系統故障不歸咎學生 |
| 外部錯誤 | 模擬無法辨識的英文後端錯誤 | 中文說明操作失敗，原始診斷保留 |
| 考試重設 | 查看確認警告並取消 | 清除後果清楚，取消不重設 |

## 驗收紀錄

依 [spec.md](spec.md) 的 SC-001 至 SC-005 記錄九區域文案覆蓋、譯名一致性、高風險操作結果與管理員／助教走查結果。憲法要求的全專案測試及覆蓋率須另於合併門檻確認；既有缺口不能以本功能測試通過代替。
