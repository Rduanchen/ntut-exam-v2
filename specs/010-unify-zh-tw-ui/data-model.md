# Data Model: 介面文字與顯示對照

本功能不新增持久資料、後端實體或狀態轉移。下列為介面設計概念，供文案清冊與驗收使用。

## 可見文案項目（Visible Copy Item）

| 欄位 | 含義 | 規則 |
| --- | --- | --- |
| 區域 | 九個主要導覽區域或共用元件 | 每項須可定位至使用情境 |
| 情境 | 導覽、標題、欄位、動作、狀態、提示、錯誤、對話框等 | 含正常與例外狀態 |
| 繁體中文文字 | 使用者實際看見的內容 | 台灣用語；不得改變操作含義 |
| 必要英文 | 技術代碼、縮寫、產品、語言、格式、單位或固定確認字串 | 保留理由可說明；必要時附中文含義 |
| 原始來源 | 介面固定文字、資料值、外部診斷或使用者輸入 | 後三者不得被無條件改寫 |

## 顯示對照（Presentation Mapping）

| 欄位 | 含義 | 規則 |
| --- | --- | --- |
| 領域 | 考試階段、設備、評測、警告、設定來源等 | 同一領域用語一致 |
| 原始值 | 既有狀態或結果代碼 | 保持逐字不變 |
| 顯示名稱 | 繁體中文名稱或原碼加中文解釋 | 不得用顯示名稱作為操作判斷 |
| 補充說明 | 使用者需理解的後果、歸因或診斷 | 不得混淆學生錯誤與系統錯誤 |
| 未知值處理 | 原始值與中文情境說明 | 不推測不存在的含義 |

## 高風險確認提示（Critical Confirmation Copy）

| 欄位 | 含義 | 規則 |
| --- | --- | --- |
| 操作 | 解除綁定、註銷、重設等 | 必須明示真正影響 |
| 警告 | 線上學生登出、資料清除等後果 | 中文完整可讀 |
| 固定輸入 | 既有 `CONFIRM` 等條件 | 保持逐字比對 |
| 取消 | 不執行操作 | 與原有行為一致 |

**Relationships**: 每個頁面包含多個可見文案項目；多個項目可共用一組顯示對照。高風險確認提示同時是一組文案項目，但須額外核對警告與確認條件。
