# 全專案環境標準化

## 緣起與問題
目前專案（包含 Host 端、前端、後端）的 `package.json` 中缺乏統一的 Node.js 版本規範（未設定 `engines` 或 `.nvmrc`），這可能導致不同開發者或 CI/CD 環境下運行結果不一致。

## 解決方案提案
1. 在根目錄及各子專案的 `package.json` 加入 `engines` 限制（例如鎖定 Node.js >= 20）。
2. 增加 `.nvmrc` 以利開發者快速切換環境。
3. 在部署腳本 (`deploy.sh`, `Dockerfile`) 中落實單一伺服器及 LTS 版本的策略配置。

## 狀態
In-flight Rationale (進行中)。待執行的小型但關鍵的基礎建設任務。
